═══════════════════════════════════════════════════════════════════════════════
  WHAT TO DO IF SOMETHING BREAKS
═══════════════════════════════════════════════════════════════════════════════

1. Check Backend Logs
   - Look for errors in console/systemd logs
   - Verify environment variables are set: env | grep -i crm

2. Database Connection Issues
   - Verify PostgreSQL is running: psql -U crmuatadmin -d crm_uat -h localhost
   - Check DB_PASSWORD is correct in .env
   - Verify firewall allows connection to localhost:5432

3. HTTPS/SSL Issues
   - Verify SSL certificate is valid and not expired
   - Check ALLOWED_HOSTS includes your domain
   - Verify DNS points to your server

4. CORS Errors in Frontend
   - Make sure CORS_ALLOWED_ORIGINS matches your domain
   - Verify https:// is used (not http://)
   - Check browser console for specific CORS error messages

5. Static Files Not Loading
   - Run: python manage.py collectstatic --noinput
   - Verify Nginx/web server is configured to serve /static/ path

6. API Not Responding
   - Verify REACT_APP_API_URL is correct in frontend .env
   - Check firewall allows access to port 8000 (or 443 if proxied)
   - Verify backend service is running
